# Heet — Matrix Portfolio (Vite + React + Tailwind)

## Local dev
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy (quick options)
- **Vercel**: Import this repo, build command `npm run build`, output `dist/`
- **Netlify**: Build `npm run build`, publish directory `dist/`
- **GitHub Pages**: Set `base` in `vite.config.ts` to `/<repo>/` and deploy `dist/`
